## Goal
Animate card movement without changing or delaying game rules.

## Acceptance criteria
- [x] Motion animates the initial deal, flip, hit, split, dealer draw, and removal.
- [x] Split-hand layout changes remain clear during animation.
- [x] Controls cannot cause duplicate actions during a transition.
- [x] Reduced-motion mode removes nonessential movement.
- [x] Browser evidence shows standard and reduced-motion behavior.

## How to check
Run `npm run test:e2e -- tests/e2e/card-animation.spec.ts`.
Deal and play a hand to see card movement and action locks.
Enable reduced motion in the system and confirm that the cards update without movement.
