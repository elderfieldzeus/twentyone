## Goal
Let users change every confirmed table rule through an options menu.

## Acceptance criteria
- [x] Options cover deck count, hand shuffling, dealer hole card, and soft 17.
- [x] Options cover split limits, double after split, repeated ace splits, and blackjack payout.
- [x] Current values are clear before a user changes them.
- [x] Applying a change archives the current session and starts a new shoe.
- [x] Game play and analysis use the new options immediately.

## How to check
- Run `npx playwright test tests/e2e/table-options.spec.ts`.
- Open Table options at desktop and phone widths.
- Confirm all eight current values, change them, and select Apply options.
- Confirm the table clears and the next hand and analysis show the new rules.
