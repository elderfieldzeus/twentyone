## Goal
Let users change every confirmed table rule through an options menu.

## Acceptance criteria
- [ ] Options cover deck count, hand shuffling, dealer hole card, and soft 17.
- [ ] Options cover split limits, double after split, repeated ace splits, and blackjack payout.
- [ ] Current values are clear before a user changes them.
- [ ] Applying a change archives the current session and starts a new shoe.
- [ ] Game play and analysis use the new options immediately.
