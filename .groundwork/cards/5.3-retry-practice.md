## Goal
Let a user retry a move from the exact saved decision state.

## Acceptance criteria
- [ ] A move graded `Not the best move` provides a retry action.
- [ ] Retry restores the exact cards, shoe state, and table rules.
- [ ] The user receives fresh feedback after the retry action.
- [ ] Retry does not change the original hand, archive, or session statistics.
- [ ] A complete browser test covers play, review, retry, and unchanged history.
