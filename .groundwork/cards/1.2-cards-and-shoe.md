## Goal
Model cards, decks, shuffling, dealing, and shoe state independently from the interface.

## Acceptance criteria
- [x] A deck contains the correct ranks, suits, and blackjack values.
- [x] A shoe supports the configured deck count and deals each card at most once.
- [x] A shuffle can start a fresh shoe after each hand.
- [x] A persistent shoe reports the exact cards that remain across hands.
- [x] Automated tests cover one-deck and six-deck shoes.

## How to check
Run `npm run test:unit -- tests/unit/cards-and-shoe.test.ts`.
