## Goal
Compare all valid actions and return stable learning feedback.

## Acceptance criteria
- [ ] The evaluator compares expected values for every valid move.
- [ ] It labels the selected action as `Best move` or `Not the best move`.
- [ ] Equal best expected values receive the same best grade.
- [ ] Probabilities format to one decimal place and expected value formats to two.
- [ ] Automated tests cover best moves, tied moves, and unavailable moves.
