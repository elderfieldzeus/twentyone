## Goal
Compare all valid actions and return stable learning feedback.

## Acceptance criteria
- [x] The evaluator compares expected values for every valid move.
- [x] It labels the selected action as `Best move` or `Not the best move`.
- [x] Equal best expected values receive the same best grade.
- [x] Probabilities format to one decimal place and expected value formats to two.
- [x] Automated tests cover best moves, tied moves, and unavailable moves.

## How to check
Run `npm run test:unit -- tests/unit/best-move.test.ts`.
