## Goal
Let a user play a normal hand through the casino interface.

## Acceptance criteria
- [ ] A user can deal a hand, hit, stand, and double down.
- [ ] Controls enable only actions that the game engine allows.
- [ ] The dealer reveals and draws cards at the correct time.
- [ ] The interface clearly shows the active hand and final result.
- [ ] Keyboard, touch, and screen-reader users can operate every action.

## How to check
Run `npm run test:e2e -- tests/e2e/core-gameplay.spec.ts`.
Open the table, deal a hand, and use hit, stand, and double down.
Confirm that the dealer card stays hidden until the player hand ends.
