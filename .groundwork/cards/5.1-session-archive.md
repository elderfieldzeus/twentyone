## Goal
Save complete sessions and hands locally for later learning review.

## Acceptance criteria
- [x] Archived sessions include their summary, rules, hands, and time.
- [x] Saved hands include cards, actions, grades, probabilities, and result.
- [x] Archives survive a page reload without a server or database.
- [x] Users can delete saved history through a separate confirmed action.
- [x] Invalid saved data does not prevent the app from starting.

## How to check
- `npx playwright test tests/e2e/session-archive.spec.ts --project=chromium`
- Complete a hand, then select Reset session.
- Open Session history and confirm that the saved totals remain after a reload.
- Split a pair, finish both hands, reset the session, and inspect the saved archive in local browser storage.
- Confirm that each split hand has its own cards, actions, grades, probabilities, and result.
- Select Delete history, cancel once, then confirm deletion.
