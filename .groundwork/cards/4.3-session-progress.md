## Goal
Track useful learning results during the current browser session.

## Acceptance criteria
- [x] The interface shows hands, wins, losses, pushes, and correct move percentage.
- [x] Each completed hand updates its result exactly once.
- [x] Each graded decision updates move accuracy exactly once.
- [x] Current progress survives a page reload through local browser storage.
- [x] Reset archives the session and starts all current counters again.

## How to check
- Run `npx playwright test tests/e2e/session-progress.spec.ts`.
- Play fast consecutive moves and confirm each grade counts once.
- Reload, reset, apply options, and deal again while a grade is pending.
- Confirm the grade reaches the correct session without stale feedback.
