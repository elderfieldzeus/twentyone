## Goal
Score all player and dealer hands under the configured blackjack rules.

## Acceptance criteria
- [x] Hand scoring handles hard totals, soft totals, multiple aces, 21, and busts.
- [x] A two-card 21 is blackjack unless it follows a split.
- [x] Equal totals and equal blackjacks produce a push.
- [x] Blackjack payout supports 3:2 and 6:5 rules.
- [x] Automated tests cover each scoring edge case.

## How to check
Run `npm run test:unit -- tests/unit/hand-scoring.test.ts`.
