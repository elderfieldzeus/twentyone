## Goal
Run a complete blackjack hand through a testable state engine.

## Acceptance criteria
- [ ] The engine supports hit, stand, double down, split, and dealer play.
- [ ] Double down deals one card and uses a theoretical two-unit result.
- [ ] Same-value cards can split into no more than the configured hand limit.
- [ ] Split ace, second split, and double-after-split rules follow the active options.
- [ ] Dealer hole-card, no-hole-card, and soft-17 rules follow the active options.
- [ ] Automated tests cover valid actions, blocked actions, and hand completion.
