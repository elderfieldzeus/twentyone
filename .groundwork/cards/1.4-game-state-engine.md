## Goal
Run a complete blackjack hand through a testable state engine.

## Acceptance criteria
- [x] The engine supports hit, stand, double down, split, and dealer play.
- [x] Double down deals one card and uses a theoretical two-unit result.
- [x] Same-value cards can split into no more than the configured hand limit.
- [x] Split ace, second split, and double-after-split rules follow the active options.
- [x] Dealer hole-card, no-hole-card, and soft-17 rules follow the active options.
- [x] Automated tests cover valid actions, blocked actions, and hand completion.

## How to check
Run `npm run test:unit -- tests/unit/game-state.test.ts`.
