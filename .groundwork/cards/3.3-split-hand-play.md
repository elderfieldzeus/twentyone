## Goal
Show and control multiple split hands without losing the active-hand context.

## Acceptance criteria
- [ ] Same-value cards expose the split action when rules allow it.
- [ ] Split hands appear separately and identify the active hand.
- [ ] Play advances through each hand before dealer play starts.
- [ ] The interface supports the configured limit of up to four hands.
- [ ] Split ace and repeated split behavior follows the active options.

## How to check
Run `npm run test:e2e -- tests/e2e/split-hand-play.spec.ts`.
Deal a same-value hand and select Split.
Confirm that each hand is separate and the gold border follows the active hand.
