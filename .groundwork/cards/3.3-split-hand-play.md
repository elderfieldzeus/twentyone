## Goal
Show and control multiple split hands without losing the active-hand context.

## Acceptance criteria
- [x] Same-value cards expose the split action when rules allow it.
- [x] Split hands appear separately and identify the active hand.
- [x] Play advances through each hand before dealer play starts.
- [x] The interface supports the configured limit of up to four hands.
- [x] Split ace and repeated split behavior follows the active options.
- [x] At 375 pixels, the carousel shows one hand per page when two or more hands exist.
- [x] At 768 and 1440 pixels, the carousel shows two hands per page when three or more hands exist.
- [x] Previous and next controls show the visible hand range and never add horizontal page overflow.
- [x] The carousel follows the active hand without replaying card deal animations.
- [x] An inactive page replaces game actions with a button that returns to the active hand.
- [x] Reduced-motion mode changes pages without slide motion.

## How to check
Run `npm run test:e2e -- tests/e2e/split-hand-play.spec.ts`.
Deal a same-value hand and select Split.
Confirm that each hand is separate and the gold border follows the active hand.
At phone width, use the arrow controls to move between split hands.
On larger screens, confirm that a third hand moves to a second page.
